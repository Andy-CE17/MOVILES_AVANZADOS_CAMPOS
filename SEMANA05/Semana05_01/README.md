# Semana 05 - Actividad 01: Introducción a UIKit

## Descripción

Aplicación desarrollada con UIKit y Storyboard para practicar el uso de componentes visuales y restricciones de Auto Layout.

## Requisitos de la guía

- Crear un proyecto iOS con UIKit y Storyboard.
- Agregar una etiqueta con el texto `Diseño y Desarrollo de Software`.
- Agregar otra etiqueta con el nombre del estudiante.
- Aplicar un color de fondo y un tamaño de letra mayor a la segunda etiqueta.
- Utilizar restricciones de Auto Layout.
- Verificar la interfaz en orientación vertical y horizontal.

## Funcionalidad

La pantalla presenta el título de la asignatura y el nombre **Andy Luis Campos Escandón**. Ambos elementos utilizan restricciones para conservar su posición cuando cambia la orientación del dispositivo.

## Tecnologías utilizadas

- Swift
- UIKit
- Storyboard
- Auto Layout
- Xcode

## Ejecución

Desde la raíz del repositorio, abrir el proyecto con:

```bash
open SEMANA05/Semana05_01/Semana05_01.xcodeproj
```

Luego seleccionar un simulador de iPhone y presionar `Command + R`.

Para comprobar el diseño adaptable se puede girar el simulador con `Command + Flecha izquierda` o `Command + Flecha derecha`.

## Evidencias

Las capturas de la aplicación en orientación vertical y horizontal se guardarán en la carpeta `Evidencias` después de ejecutarla en el simulador.
